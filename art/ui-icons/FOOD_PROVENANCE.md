# B09 food icons

Three original project-authored 96×96 SVGs: a compartmented bento, star-labelled
cola bottle and steaming curry plate. No external reference sheet, contributor
asset, tracing or downloaded image is used. Permission basis: original project
artwork, distributed with this repository under its project terms.

Authoring source: `art/ui-icons/food-icons.json` and literal vector paths in
`scripts/assets/build_food_icons.mjs`. Rebuild with `npm run assets:food`.
`food-provenance.json` records SHA-256 for both inputs and each generated SVG.
Generation has no timestamp, random value, network request or existing-asset
rewrite. Runtime files are only `public/assets/food/*.svg`; food is separate
from the 65 equipment icons and 55 recipes.

Generation was performed on 2026-11-06. Asset parsing, visual inspection and
validation are NOT RUN pending the owner's verification decision; generation
alone is not a validation result.
